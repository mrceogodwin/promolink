# PromoLink

**Your Audience. Your Opportunity.**

PromoLink is a marketplace connecting owners of WhatsApp TV pages, WhatsApp groups, Telegram channels, Facebook Pages, and other eligible social audiences with advertisers looking to promote products and services.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- React 19

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
